# 學道 · 학도

> 배움을 잇고, 졸업으로 향하는 길.

현재 이수 상태와 남은 졸업 요건을 확인하고, 학기별 수강 계획을 추천·수정하는 졸업 여정 도우미입니다.
대상: 명지대학교 자연캠퍼스 컴퓨터공학과 2023학번 (MVP)

> ⚠ 졸업 학점·과목·선수과목·개설 학기는 **검증되지 않은 샘플 데이터**입니다. 공식 졸업 판정이 아닙니다.

## 기능
1. **현재 상태 등록 및 남은 요건 확인** — 과목을 골라 이수 완료/수강 중으로 등록, 총학점·영역별 부족 학점·미이수 필수 과목 계산
2. **학기별 수강 계획 추천** — 선수과목·개설 학기·학년 제한·희망 학점을 확인한 조건 기반 추천과 추천 이유
3. **계획 수정 및 예상 결과 재계산** — 학기 이동·추가·빼기 시 조건 검사와 예상 충족 현황 즉시 갱신

회원가입 없이 이 기기의 브라우저(localStorage)에만 저장합니다.

## 실행
빌드가 필요 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나:

```bash
python3 -m http.server 5179
```

## 구조
| 파일 | 역할 |
|---|---|
| `js/data.sample.js` | 샘플 기준 데이터 (학교 기준 확보 시 이 파일만 교체) |
| `js/engine.js` | 계산·추천·검증 (화면과 분리된 순수 함수) |
| `js/store.js` | 브라우저 저장 |
| `js/app.js` | 화면·라우팅·조작 |
| `js/ink-road.js`, `js/ink-line.js` | 수묵 붓길·산수·세로 먹선 |
| `tests/engine.test.html` | PRD 검증표 테스트 (브라우저로 열기) |
| `DESIGN.md` | 디자인 시스템 |
